# 2. What GitHub Copilot Can Do In VS Code

## Purpose

Show attendees the main Copilot experiences inside Visual Studio Code so they understand where Copilot fits into the editor workflow.

## Key Message

Copilot is not a single feature. In VS Code, it shows up as inline suggestions, chat, editing assistance, explanations, workspace-aware help, and a way to reason through problems while staying close to the code.

## Talking Points

- Inline suggestions help complete code as you type.
- Copilot Chat can answer questions, generate examples, explain code, and help troubleshoot errors.
- Chat participants and context references can focus Copilot on files, selections, terminal output, or workspace context.
- Copilot can help with refactoring, tests, documentation, and script improvements.
- Copilot works best when the workspace contains useful context: scripts, README files, examples, configuration, and naming conventions.

## Demo Ideas

- Type the beginning of a PowerShell function and show inline completions.
- Select a small script and ask Copilot to explain what it does.
- Ask Copilot to add comment-based help to a PowerShell script.
- Ask Copilot to improve parameter validation or error handling.

## Suggested Prompt Examples

```text
Explain what this PowerShell script does and identify anything risky before I run it.
```

```text
Add comment-based help and examples to this function without changing its behavior.
```

```text
Refactor this script so it has clear parameters, basic validation, and readable output.
```
