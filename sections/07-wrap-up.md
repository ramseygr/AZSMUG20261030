# 7. Wrap-Up

## Purpose

Close with a memorable, practical summary and give attendees clear next steps.

## Key Message

GitHub Copilot is most valuable when it helps you stay in motion while still thinking clearly. The core workflow is simple: prompt, generate, review, test, refine, and document.

## Recap Points

- Copilot in VS Code can help with suggestions, chat, explanations, refactoring, debugging, tests, and documentation.
- Better prompts include the goal, context, constraints, and desired output.
- Cloud automation is a strong fit because many tasks involve scripts, configuration, commands, and repeatable patterns.
- Generated code should be treated as a draft.
- Safe review and testing habits matter more as AI makes iteration faster.

## Suggested Closing

"The real shift is not that Copilot writes perfect code for us. The shift is that we can now have a useful technical conversation inside the editor while we work. For cloud automation, that means getting from idea to draft faster, asking better questions, and improving the result without losing control of the work."

## Attendee Next Steps

- Install or update Visual Studio Code.
- Enable GitHub Copilot and Copilot Chat.
- Try Copilot on a small, non-production script.
- Practice the goal/context/constraints/output prompt pattern.
- Ask Copilot to explain code before asking it to change code.
- Build a personal prompt library for recurring automation tasks.

## Q&A Prompts

- What cloud automation tasks do you repeat often?
- Where do you get stuck when starting a script?
- What kinds of generated code would you feel comfortable using after review?
- What guardrails would your team need before using Copilot broadly?

## Timing

Target: 5 minutes plus Q&A.
