Copilot In VS Code

Copilot shows up where the work is happening.

  • Inline suggestions while you type
  • Chat for questions, generation, explanation, and debugging
  • Workspace context from files, selections, and terminal output
  • Help with tests, documentation, refactoring, and reviews
Prompt Pattern

Useful prompts have four parts.

Goal: What I want to accomplish. Context: The tool, language, file, or environment. Constraints: What must or must not happen. Output: The format I want back.

Explain and improve a script.

Cloud Automation Use Cases

Good demos are useful, safe, and easy to inspect.

  • Azure resource inventory
  • Script explanation and risk review
  • Broken script troubleshooting
  • Operational documentation generation
Demo 2

Build an Azure inventory helper.

Start from plain language, generate a read-only script, add parameters, improve output, review the result, then ask Copilot to create usage documentation.

Guardrails

Generated code is a draft.

  • Review before running
  • Protect secrets and tenant data
  • Prefer read-only demos and least privilege
  • Validate in a safe environment before production
Next Steps

Try it on one small automation task.

  • Use the goal, context, constraints, output pattern
  • Ask Copilot to explain before changing code
  • Keep a personal prompt library
  • Build review and testing into the loop
