Copilot In VS Code

Copilot shows up where the work is happening.

  • Inline suggestions while you type
  • Chat for questions, generation, explanation, and debugging
  • Workspace context from files, selections, and terminal output
  • Help with tests, documentation, refactoring, and reviews
Prompt Pattern

Useful prompts have four parts.

Goal: What I want to accomplish. Context: The tool, language, file, or environment. Constraints: What must or must not happen. Output: The format I want back.

Looking Ahead

Vibe coding vs. spec-driven development

Vibe coding Explore through conversation: prompt, review, test, and refine as the idea takes shape.
Spec-driven development Make intent explicit first: agree on requirements and acceptance criteria, then guide implementation and tests with a shared spec.

More structure as scope and team needs grow. Both still need iteration and review.

Beyond today's scope: explore GitHub Spec Kit next.
